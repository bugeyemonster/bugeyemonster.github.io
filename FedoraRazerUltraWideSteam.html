Fixing Darktide on Linux: Audio Playing with Invisible Screen on Ultrawide Monitors

The Issue

When launching Warhammer 40,000: Darktide on Linux (especially in dual-GPU laptop setups outputting via HDMI to an external ultrawide display), the game may start in the background with full audio playback, but no visible game window renders on screen.

This occurs because the game defaults to exclusive fullscreen mode targeting display index 0 (the laptop's internal panel) at an unsupported aspect ratio. When outputting to an external monitor under Wayland or XWayland, the display surface fails to map. Additionally, the bundled Fatshark launcher can hang as an invisible process.

Step 1: Force Borderless Window and Native Resolution

You must manually set the window mode and resolution inside the game's Proton configuration file.

Open a terminal and edit user_settings.config using a text editor:

nano ~/.local/share/Steam/steamapps/compatdata/1361210/pfx/drive_c/users/steamuser/AppData/Roaming/Fatshark/Darktide/user_settings.config
Note: If the game is installed on a secondary Steam library drive, replace the base path with your library location.

Locate the display settings and update them to force borderless fullscreen:

borderless_fullscreen = true
fullscreen = false
screen_mode = "fullscreen"

Update the resolution array to match your monitor's native dimensions (e.g., 5120x1440 for DQHD or 3840x1080 for DFHD):

screen_resolution = [
  5120
  1440
]

Save the file and exit (Ctrl+O, Enter, Ctrl+X in nano).

Step 2: Bypass Launcher & Increase Lua Heap Size in Steam

Bypassing the Fatshark launcher prevents the WebView window hang, and allocating more Lua memory prevents crashes during mission loading.

  1. Open Steam and right-click Warhammer 40,000: Darktide → Properties.
  2. In the General tab, add the following to Launch Options: 
    %command% --launcher-skip --lua-heap-mb-size 2048
  3. In the Compatibility tab, check Force the use of a specific Steam Play compatibility tool and select GE-Proton (or Proton Experimental).

Summary

Setting borderless_fullscreen = true along with exact monitor dimensions in user_settings.config allows XWayland to map the window properly to the external ultrawide display. Bypassing the launcher ensures immediate execution directly through the Proton runtime.
